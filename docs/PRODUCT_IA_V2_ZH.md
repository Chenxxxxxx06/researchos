# ResearchOS V2 产品信息架构

## 1. 产品定位

ResearchOS 是证据优先的科研生产工作台。它连接研究资料、文献证据、Research Mission、代码版本、实验运行、论文主张和发布资产。产品的首要目标不是增加更多独立工具，而是让每一步都可恢复、可审批、可追溯。

## 2. 导航模型

一级项目导航收束为七个入口：

1. 概览
2. 研究任务
3. 资料与证据
4. AI IDE
5. 实验
6. 论文
7. 发布

高级入口通过“更多”菜单和上下文入口访问：

- Agent 协作归入研究任务
- 文献中心、科研收件箱和会议 DDL 归入资料与证据
- 模拟审稿归入论文
- 管理中心归入项目设置

现有 URL 在 V2 阶段保持兼容，避免破坏书签、测试和已有工作流。

## 3. 页面职责

### 概览

回答当前进度、待处理审批和下一步行动。首屏只保留一个主要行动，并展示来自真实持久化对象的项目状态。

### 研究任务

管理范围确认、检索、阅读卡、综述、实验方案、审批门禁、Agent DAG、事件和产物。Agent 协作是 Mission 的高级执行视图，不是普通用户必须理解的独立概念。

### 资料与证据

统一 Research Inbox、Research Copilot、文献库、论文发现、阅读器、Zotero 和会议 DDL。主工作区保持专注，文库和发现面板允许按需收起。

### AI IDE

提供文件、编辑器、终端、Git、Coding Agent 和补丁审批。中心编辑器拥有最高空间优先级，左右面板可收起，SSH 和本地运行时使用同一状态栏。

### 实验

以运行记录为主对象，组织实验计划、运行、配置、日志、指标、Artifacts、对比和论文资产。完成状态不能显示为 0% 等互相冲突的信息。

### 论文

整合 LaTeX 编辑、预览、结果锚点、图表、引用和模拟审稿。支持专注写作、编辑预览和证据审稿三种工作模式。

### 发布

将事实包检查、资产生成、补丁审查、构建验证和发布组织成一条 Release Pipeline。任何缺失事实保留为 TODO，不允许 Agent 补造。

## 4. 布局规则

- 顶部栏高度 64px
- 桌面主导航宽度 84px
- Context Panel 默认 224px 到 272px
- Inspector 默认 352px 到 416px
- Context Panel 和 Inspector 必须可收起
- 1280x720 为首要桌面验收尺寸
- IDE 与论文工作区提供 Focus Mode
- 移动端只显示核心入口，重型编辑能力提供明确降级

## 5. 不可破坏项

- API 路径与共享 Schema
- 现有项目路由
- 权限、审批和审计语义
- 表单字段与已有数据模型
- WebSocket 事件契约
- 用户已有工作区文件
- 未提交的用户源码和个人材料
