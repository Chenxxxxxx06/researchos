01 / 为什么

"论文里的这条结论，来自哪篇文献、哪个实验、哪个 commit 和哪份 artifact？"

科研工具彼此割裂，聊天记录又无法承担科学证据。ResearchOS 的核心不是生成更多文字， 而是让每个公开主张最终指向可核查的工作过程。

02 / HARNESS

一个上下文。
多个专家 Agent。

Coordinator 只负责拆解、调度、验证和合并。每个专项 Agent 拥有明确 Artifact， 所有高风险动作经过人工闸门。

⌁

Provenance-first

Claim → Evidence → Run → Artifact → Commit。模型输出默认只是候选。

◫

Context with boundaries

规则、科学事实、会话和学习者记忆分层管理，不做一个混乱的"大向量库"。

◇

Human-governed

Scope、Evidence、Release 三道闸门。证据不足、预算耗尽或重复失败就停止。

04 / TERMINAL

从终端启动
科研 Harness。

同一个 API 服务于 Web、IDE 和 CLI。当前 alpha 已支持登录、项目切换、 Agent Turn、交互会话、上下文查看、科研记忆与 Mission scaffold。
